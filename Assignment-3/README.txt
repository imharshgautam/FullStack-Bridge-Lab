ASSIGNMENT 3 — JavaScript Solutions
===================================

Includes 10 separate JavaScript files, one per question.

Run a file using Node.js:
  node Q1_Dynamic_Data_Parser.js

Repeat with the desired filename for Q2–Q10.

The scripts use core JavaScript only and print output through console.log().
They include comments about strict mode, hoisting, validation, error handling,
scope, and debugging. Debugging exercises include suggested breakpoints and
watch variables; use VS Code's Run and Debug panel to follow those steps.

Notes:
- Q1 treats whitespace-only strings and non-finite conversions as invalid numeric data.
- Q5's unsafe original sequence is explained in comments; the corrected sequence runs.
- Q8's invalid strict-mode code is commented out because duplicate parameters prevent parsing.
- Q6 defaults to 5 rows; edit userInputRows to change the row count.
