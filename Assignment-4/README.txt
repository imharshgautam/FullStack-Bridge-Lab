How to run:
1. Console-based questions (Q1, Q3, Q6, Q9): run with Node.js, e.g.
   node Q1_Ecommerce_Product_Manager.js
2. Form/DOM questions (Q2, Q4, Q5, Q7, Q8): open the matching HTML file in a
   browser. The HTML loads its matching JavaScript file.
3. No frameworks or external libraries are used.

Notes:
- Q2 and Q5 use practical email/name/phone validation patterns.
- Q4 uses textContent for displaying submitted JSON to avoid interpreting it as HTML.
- Q9 interprets SAVE20 / DISC10 as 20% / 10% discounts.
