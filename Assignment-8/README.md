# Assignment 8 – JavaScript Solutions

Contains separate `.js` files for all 9 questions. The solutions use core
JavaScript (ES6+) and include comments, sample data, and console output.

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open a terminal in the folder.
4. Run an individual question, for example:

```bash
node Q1_student_result_processing.js
```

Use the corresponding filename for Q2 through Q9.

## Notes
- No frameworks or external npm packages are required.
- Node.js 16+ is recommended for private class fields and the JavaScript
  features used here.
- Q1 uses an example grading scale: A >= 80, B >= 60, C >= 40, otherwise F.
- Q2 and Q5 use ₹ for sample prices/fare; change the currency if needed.
- Q6 sorts a copy of the product array to preserve the original.
- Q7 demonstrates private `#balance` and catches an insufficient-funds error.
- Q8 demonstrates prototype lookup from an OnlineTicket instance to
  MovieTicket.prototype.
