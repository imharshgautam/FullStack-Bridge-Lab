ASSIGNMENT 1 — CORE JAVASCRIPT

Contents:
- Q1 through Q10: one separate .js file for each question.

How to run:
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run a file with: node Q1_Personalized_Login_Greeting.js
4. Replace the sample values in each file to test other cases.

Notes:
- These programs use core JavaScript only; no frameworks or libraries are required.
- Q1 uses the computer's current local hour.
- Q7 prints the secret number to make testing easier. Remove that line for a real guessing game.
- Q10 follows the stated age thresholds: citizens aged 18–20 receive the “vote only” message; citizens aged 21+ receive the “all services” message.
